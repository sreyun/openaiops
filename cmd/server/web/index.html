安装后自动启动中继服务，监听下方端口，转发所有请求到云监控中心。Linux 使用 sudo -E 以保留 AIOPS_RELAY_SECRET。

          
服务端与网关须配置相同 AIOPS_RELAY_SECRET（未设置则不校验）；密钥不一致会导致中继鉴权失败。

          
网关中继安装不写入分组/Token；一级分组请写在②内网安装命令。

        

        

          

            
            
          

          

            
            
          

        

        

          
          

            

            
          

          
内网机器通过网关中继连接云监控中心，无需直连公网。填写网关 IP 后命令会自动更新。

          
经中继拉取的脚本会把 server 改写为网关地址，并去掉 servers[]（与中继互斥）。

        

      

      

        
        

          

          
        

        
在被监控主机执行即可停止服务并移除 Agent。
